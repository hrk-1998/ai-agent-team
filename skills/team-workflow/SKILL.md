# Team Workflow

Master orchestrator runs this in main session.

1. Clarify (team-lead-product): Brief with Fact/Assumption/Unknown. Gate 1 owner approval, FA simple.
2. Plan (team-lead-planning): Architecture + TaskContract + deps. Foundation keeper writes 5 files. Gate 2 + 2.5.
3. Build (team-lead-build): scoped Build Mode, lease, snapshot, small commits.
4. QA (team-lead-qa): diagnosis RO, repair bounded, judges RO, visual QA real screenshot.
5. Release (team-lead-release): sec + release judges RO. Critical override. Rollback plan.
6. Handoff (team-lead-memory): HANDOFF.md 14 fields.

Machine edges EN. Owner edge FA simple. Subs same-as-lead model. No gate skipped.
Owner questions: ONE at a time, strict order, 2-4 options each plus free-text fallback. Wait for answer before next.
